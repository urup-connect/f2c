# Azure Blob Storage backend for the club document PDFs, so an admin upload lands
# in the container the CDN fronts. The extra pulls azure-storage-blob. Only
# imported once DJANGO_DOCUMENT_STORAGE_CONTAINER is set; without it the
# documents fall back to MEDIA_ROOT and none of these is touched.
django-storages[azure]>=1.14,<2.0
# Managed-identity credentials, so App Service needs no account key in its
# application settings. Imported only when no key, SAS token or connection
# string is configured -- see documents/storage.py.
azure-identity>=1.19
# Decoding and re-encoding member avatars (accounts/avatars.py). Every uploaded
# image is decoded and written back out by Pillow rather than stored as it
# arrived, which is what strips EXIF and refuses a file that only claims to be
# an image.
pillow>=11.0
# The MySQL driver. QA and production are MySQL 8.4; a developer with no
# DJANGO_DB_HOST set runs on SQLite and never loads this, but it installs
# everywhere so that a deployment cannot be one forgotten package away from not
# booting.
#
# It is a C extension, and **the published wheels are Windows-only**. On Linux
# pip builds it from the source tarball, which needs the MySQL client headers, a
# compiler and pkg-config:
#
#   sudo apt-get install -y pkg-config default-libmysqlclient-dev build-essential
#
# .github/workflows/ci.yml does that before installing. Any Linux deployment has
# to as well.
mysqlclient>=2.2.8,<3.0
# The client Django's own RedisCache backend imports. Named here because it was
# missing: `[project.dependencies]` has carried it since the throttle counters
# moved off LocMemCache, and this file did not -- so anyone installing the
# documented way got a backend that raises on the first cache read. See
# f2c/cache.py.
redis>=5.2,<7.0
# Reading and writing the cultivator stock-upload template (plant/spreadsheet.py).
# Pure Python, no system libraries, so unlike mysqlclient above it needs nothing
# installed on the host. `cultivator-stock-upload.md` asks for an Excel template
# specifically; a CSV would have no dropdown of the cultivator's own strains,
# which is the part that stops the most common upload mistake being made.
openpyxl>=3.1,<4.0
